## 🚀 HƯỚNG DẪN ĐƯA LÊN GITHUB & BẬT GITHUB PAGES (CHỈ 1 PHÚT)

Thầy/Cô có thể đưa lên GitHub cực kỳ nhanh theo các bước:

1. **Đăng nhập vào GitHub**: Truy cập [https://github.com](https://github.com).
2. **Tạo Repository mới**:
   - Bấm vào dấu `+` ở góc trên bên phải -> chọn **New repository**.
   - Đặt tên Repository: `TA2-SENTENCE-BUILDING` (hoặc tên tùy thích).
   - Chọn chế độ: **Public** (Bắt buộc chọn Public để dùng GitHub Pages miễn phí).
   - Tích chọn **Add a README file** -> bấm nút xanh **Create repository**.
3. **Tải file lên**:
   - Trong trang repository vừa tạo, bấm nút **Add file** -> chọn **Upload files**.
   - Kéo thả file `index.html` và file `logo-tdc.png` trong thư mục `d:\websiteabc\TA2-SENTENCE BUILDING` vào ô tải lên.
   - Cuộn xuống dưới cùng và bấm nút xanh **Commit changes**.
4. **Bật GitHub Pages để lấy link website cho sinh viên**:
   - Bấm vào tab **Settings** của repository (trên thanh menu ngang phía trên).
   - Ở cột menu bên trái, tìm và bấm chọn **Pages**.
   - Tại phần **Build and deployment** -> **Branch**:
     - Chọn nhánh: **main** (hoặc `master`).
     - Chọn thư mục: **/ (root)**.
     - Bấm nút **Save**.
   - Đợi khoảng 1 phút rồi tải lại trang (F5), Thầy/Cô sẽ nhận được đường link:
     > `https://<ten-tai-khoan>.github.io/TA2-SENTENCE-BUILDING/`
   - 👉 **Gửi đường link này cho sinh viên để vào làm bài ngay lập tức!**
